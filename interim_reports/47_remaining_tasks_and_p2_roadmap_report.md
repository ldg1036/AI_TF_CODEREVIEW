# 47. 잔여 작업 현황 및 4단계 P2 로드맵 보고서

## 1. 개요
본 보고서는 10_개선가이드_로드맵 문서 기준 현재까지 완수된 P0 및 P1 항목(100% 완수)을 제외하고, 향후 추진 가능한 잔여 작업(P2 영역 4단계 및 배포 운영 정비)의 전체 목록과 세부 내용을 명확히 정리한 결과입니다.

## 2. 완수된 완료 단계 요약 (100% 완료)
* 1단계 P0: 저장소 위생 정리 및 CI CD 구축 완료 (100%)
* 2단계 P1: 실검증 데이터 확보 및 아키텍처 견고성 강화 완료 (100%)
* 3단계 P1: 코드리뷰 기능 심층 개선 완료 (100%)

## 3. 남아있는 잔여 작업 목록 (P2 중기 조치 영역)

### 3.1 CLI 빌드 파이프라인 심각도 임계치 옵션 (`--fail-on-severity`)
* CLI 실행 시 `--fail-on-severity High` 지정 시 지정 심각도 이상의 위반 존재 시 프로세스 exit code 1 반환 지원

### 3.2 인코딩 감지 신뢰도 명시적 경고 UI
* 파일 파싱 시 인코딩 감지 신뢰도가 낮은 경우 UI 및 리포트에 명시적인 인코딩 주의 경고 표시

### 3.3 리포트 히스토리 비교 diff 대시보드 강화
* 이전 검사 run 대비 신규 발생(Added), 해결됨(Resolved), 재발/유지(Remained) 항목을 다층 diff 그래프로 시각화

### 3.4 릴리스 자동화 파이프라인 태그 연동
* GitHub Actions 기반 `git tag v*` push 시 실행 바이너리 패키징 및 Releases 이관 자동화 테스트

## 4. 향후 조치 제언
* 현재 P0 및 P1 핵심 과제(25개)가 모두 100% 구현 완료되었으므로, 잔여 P2 과제에 대해서도 사용자의 승인에 따라 즉시 4단계 구현에 착수하여 전체 프로젝트를 완성할 수 있습니다.
