## 1. 정적 분석 기능 6대 심층 보완 로직 제안

### 1.1 완전 제어 흐름 그래프(CFG) 기반 도달 불가능 코드 및 중복 조건 분석
* **현재 상태**: AST 기반 단일 노드 검사를 통해 직관적인 무한 루프나 지연 함수 누락을 적발합니다.
* **보완 로직**:
  * 스크립트 실행 경로를 그래프 노드로 분기하는 제어 흐름 그래프(Control Flow Graph, CFG) 탐색기 구축.
  * 복잡한 `switch case` 또는 조건 분기 결합 시 절대로 도달할 수 없는 도달 불가능 코드(Dead Code) 및 중복 조건식(예: 외부 `if (val > 10)` 내부 `if (val > 5)`)을 100% 정적 감지.

### 1.2 단일 정적 대입(SSA) 기반 변수 초기화 전 참조(Uninitialized Read) 추적
* **현재 상태**: 변수 선언 유무 및 단순 섀도잉 여부 검사.
* **보완 로직**:
  * SSA(Static Single Assignment) 폼 변환 기술을 적용하여 모든 변수의 생성, 대입, 사용 시점을 추적.
  * 변수가 대입문 없이 `dpGet()`의 인자나 조건 판단문의 변수로 전달되는 초기화 전 사용 결함을 정밀 분석.

### 1.3 WinCC OA 이벤트 리스너 해제 누수 추적 (dpConnect / dpDisconnect Balancing)
* **현재 상태**: `dpConnect` 선언 시 지정된 콜백 함수가 존재하는지 유효성 검사.
* **보완 로직**:
  * 패널 종료 이벤트(`panelOff`)나 스코프 탈출 시점에 등록된 `dpConnect` 이벤트 리스너가 대응하는 `dpDisconnect`로 해제되는지 이벤트 수명주기(Lifecycle Balancing) 추적.
  * 이벤트 리스너 누수(Listener Leak)로 인한 SCADA 메모리 증가 방지.

### 1.4 비동기 콜백 전역 변수 경쟁 상태(Race Condition) 정적 검사
* **현재 상태**: 전역 변수와 지역 변수 간 이름 중복(Shadowing) 검사.
* **보완 로직**:
  * WinCC OA는 여러 `dpConnect` 콜백 함수가 비동기로 동시 실행되는 구조입니다.
  * 복수의 콜백 함수가 동기화 구문(Mutex 또는 Flag) 없이 동일한 전역 변수를 수정하는 경쟁 상태(Race Condition) 패턴 정적 적발.

### 1.5 자원 생성 및 해제 경로 정밀 추적 (Resource Leak Analysis)
* **현재 상태**: 기초적인 SQL DB 바인딩 구문 검사.
* **보완 로직**:
  * `fopen()`, `dbOpenClass()` 등 자원 할당 함수 실행 후 중간 예외 반환 지점(`return`, `break`)에서 `fclose()`, `dbCloseClass()` 호출 없이 종료되는 자원 누수(Resource Leak Path) 추적.

### 1.6 매직 넘버 및 서브루틴 과대 복잡도 검사 (Magic Number & Cyclomatic Complexity)
* **현재 상태**: IP 주소, 버전에 대한 하드코딩 검사.
* **보완 로직**:
  * 의미를 알 수 없는 숫자 상수의 무분별한 사용(예: `delay(0, 350);`, `if (status == 99)`) 검사.
  * 순환 복잡도(Cyclomatic Complexity)를 계산하여 단일 함수 내 분기 경로가 15를 초과하는 고위험 복잡 함수 경고.

## 2. 기술적 효과 요약

위 6가지 심층 로직이 보완되면 정적 분석 엔진은 단순 **문법 린터(Linter)** 수준에서 컴파일러 수준의 **정밀 정적 분석기(Deep Static Analyzer)**로 업그레이드되어 정밀도와 결함 적발 범위를 대폭 넓힐 수 있습니다.
