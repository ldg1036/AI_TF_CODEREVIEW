# 비개발자용 3단계 설치 가이드 및 원클릭 실행 환경 구축 보고서

## 1. 개요 및 목적

본 보고서는 개발 지식이 없는 현업 검사자 및 운영 담당자가 명령 프롬프트 입력 없이 원클릭 방식으로 설치 및 실행할 수 있도록 구축된 가이드와 스크립트를 분석하고 정리합니다.
참조 대상 파일은 setup.bat, run_gui.bat, run_check.bat 및 패치 파일입니다.

## 2. 참조 파일 구성 및 역할 분석

* setup.bat
  * Python 3.12 설치 여부 및 시스템 PATH 등록 상태 자동 검증
  * 독립 실행 환경인 가상환경(.venv) 자동 생성
  * 필요 의존성 패키지 자동 설치
  * 기본 설정 파일(config/settings.yaml) 템플릿 복사 및 준비

* run_gui.bat
  * 데스크톱 화면(GUI) 기반 코드 리뷰어 프로그램 구동
  * 가상환경 존재 여부 사전 체크 및 활성화

* run_check.bat
  * 검사 대상 폴더 또는 파일을 아이콘 위로 드래그 앤 드롭하여 즉시 검사 실행
  * 검사 완료 후 output 폴더 내 HTML 보고서 자동 생성

## 3. 비개발자용 3단계 설치 및 실행 가이드

### 0단계. 파일 내려받기 및 압축 해제

1. 저장소에서 ZIP 파일을 내려받습니다.
2. 내려받은 파일의 압축을 풉니다.
3. 폴더 경로는 한글이나 공백이 없는 C:\WinCC_Reviewer 와 같은 짧은 경로를 권장합니다.

### 1단계. Python 설치 (최초 1회)

1. Python 공식 홈페이지(https://www.python.org/downloads/windows/)에서 64비트 설치 프로그램을 내려받아 실행합니다.
2. 설치 화면 맨 아래의 Add python.exe to PATH 체크박스를 반드시 선택합니다.
3. Install Now 버튼을 클릭하여 설치를 완료합니다.

### 2단계. 자동 설치 실행 (최초 1회)

1. 압축을 푼 폴더 내부의 setup.bat 파일을 더블클릭합니다.
2. 검은 창이 열리고 설치가 진행됩니다. 설치 완료 메시지가 나올 때까지 2분~5분 정도 기다립니다.
3. 알 수 없는 게시자 경고가 뜨는 경우 추가 정보 버튼을 누른 후 실행을 선택합니다.

### 3단계. 프로그램 실행 및 결과 확인

* 화면을 보며 검사하고 싶은 경우: run_gui.bat 파일 더블클릭
* 특정 폴더를 바로 검사하고 싶은 경우: 검사할 폴더를 run_check.bat 아이콘 위로 마우스 끌어다 놓기
* 검사 결과: output 폴더 안에 생성된 HTML 리포트 파일을 더블클릭하여 브라우저에서 확인

## 6. README.md와 비개발자 가이드 통합 구조 타당성 평가

README.md 파일 내에 비개발자용 설치 가이드를 직접 포함시키는 전략에 대한 분석 결과입니다.

* 장점 및 타당성
  1. 단일 접근 지점 확보: GitHub 메인 페이지 접속 시 비개발자가 별도 링크 이동 없이 즉시 3단계 설치 가이드를 확인 가능합니다.
  2. 문서 최신성 유지 용이: 설치 스크립트나 프로세스가 변경될 때 단일 문서(README.md)만 관리하므로 동기화 누락을 방지합니다.

* 고려사항 및 한계점
  1. 전체 문서 길이 증가: 개발자용 상세 아키텍처 및 CLI 사용법과 함께 수록되어 문서의 전체 길이가 길어질 수 있습니다.

* 최종 제안
