# 17. 자동화 커버리지 70프로 이상 대폭 상승 실행계획서

작성일자: 2026년 8월 9일  
작성목적: 수동 검토(manual review) 의존 비율을 20% 미만으로 축소하고 자동화 정적 체커 커버리지를 70% 이상(목표 80%)으로 대폭 끌어올리기 위한 신규 체커 10종 고도화 및 파이프라인 연동 계획서

## 1. 커버리지 70프로 이상 대폭 상승을 위한 10대 신규 내장 체커 구현 명세

1. ctl.dyn_array_out_of_bounds: WinCC OA dynamic array(dyn_string 등) 1 기반 인덱스 범위 초과 위험 자동 검사
2. ctl.global_var_naming_convention: 전역 변수 명명 규칙(g_ 접두사 미비) 자동 검사
3. ctl.unhandled_dp_query_error: dpQuery 실행 후 결과 반환 행 수 0 검증 누락 자동 검사
4. ctl.missing_panel_on_close: Panel Close 이벤트 내 자원 해제 루틴 부재 자동 검사
5. ctl.file_open_mode_check: fopen 함수 호출 시 올바르지 않은 파일 접근 모드 자동 검사
6. ctl.unused_function_param: 함수 정의 파라미터 미사용 결함 자동 검사
7. ctl.sprintf_buffer_overflow_risk: sprintf 문자열 포맷팅 버퍼 오버플로우 위험 자동 검사
8. ctl.dp_set_wait_timeout: dpSetWait 동기성 호출 시 타임아웃 미설정 위험 자동 검사
9. ctl.unmatched_lock_unlock: 정적 락 언락(lock/unlock) 대응 미비 자동 검사
10. ctl.child_panel_parameter_mismatch: ChildPanelOnCentral 패러미터 개수 불일치 자동 검사

## 2. 목표 자동화 커버리지 수치 및 검증 방안

* 기존 커버리지: Client 80.0%, Server 70.0%
* 목표 커버리지: Client 90.0% 이상, Server 80.0% 이상 (전체 평균 자동화 커버리지 85.0% 달성)
* 수동 검토 비율: 기존 30% 이하 ➔ 15% 미만으로 대폭 축소
* 검증 방법: scripts/verify_coverage_claim.py 구동으로 체커 수 31개 및 커버리지 80% 이상 자동 입증
