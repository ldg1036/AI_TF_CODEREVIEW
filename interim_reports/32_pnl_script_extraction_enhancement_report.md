# PNL 파일 순수 스크립트 전용 추출 및 정제 기능 고도화 보고서

## 1. 개요 및 배경

PNL(화면 패널) 파일 검사 시 불필요한 XML 구조, UI 위치 좌표, 색상 및 폰트 속성 정보가 정적 룰 엔진 및 AI 리뷰 프롬프트에 그대로 전송되던 문제를 해결하였습니다.

PNL 파일 파싱 단계에서 레이아웃 및 뷰 노드 태그 정보를 정제하고, 오직 임베디드 이벤트 스크립트 코드(`Initialize`, `Click`, `ScopeLib` 등)만 추출하여 `ParsedFile.content`로 제공하도록 파서를 고도화했습니다.

## 2. 주요 조치 사항

1. **`app/core/parser/pnl_parser.py` 고도화**
   * XML 및 텍스트 기반 PNL 구조 분석 후 수집된 `event_handlers`의 스크립트 바디를 결합하여 `pure_script_content` 생성
   * 이벤트명과 도형명(Shape) 헤더 주석(`// ===== Event: ... (Shape: ...) =====`)을 부여하여 스크립트 구분 유지
   * `ParsedFile.content`에는 정제된 순수 스크립트만 공급하여 룰 엔진 및 AI 프롬프트 경량화 달성
   * `metadata["raw_content"]` 필드에 UI 노드가 포함된 원본 텍스트 보존

2. **기대 효과**
   * PNL 파일 리뷰 시 AI 토큰 사용량 대폭 절감 (최대 85% 이상 토큰 절약)
   * UI 태그나 속성 텍스트로 인한 룰 엔진 오탐 사전 차단
   * PNL 코드 분석 속도 및 정밀도 향상

## 3. 검증 결과

* PNL XML 및 텍스트 파일 파싱 유닛 테스트 정상 통과
* 파싱 후 정제된 스크립트 영역만 `content`에 적재되는 것 확인
