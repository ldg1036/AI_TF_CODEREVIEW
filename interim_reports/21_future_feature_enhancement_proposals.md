## 1. 차세대 5대 기능 개선 및 확장 과제

### 1.1 CI/CD 협업 연동: GitLab 및 GitHub MR 인라인 코멘트 봇
* **개선 배경**: 현재는 로컬 CLI 또는 GUI 실행 후 리포트를 확인하는 방식입니다.
* **추가 기능**: 깃랩(GitLab)이나 깃허브(GitHub)에 Merge Request 또는 Pull Request가 등록되면, 리뷰 봇이 자동으로 작동하여 변경된 라인(Diff Line)에 직접 리뷰 인라인 코멘트를 등록합니다.
* **기대 효과**: 리뷰어가 리포트 파일을 별도로 열 필요 없이 소스 형상관리 도구 화면 내에서 즉시 검토 및 병합 승인 여부를 결정할 수 있습니다.

### 1.2 심층 코드 분석: 교차 파일 종속성 및 오염 추적 (Inter procedural Taint Analysis)
* **개선 배경**: 현재는 단일 파일 단위 AST 구문 분석 중심입니다.
* **추가 기능**: `#uses` 구문으로 연결된 복수 파일 간의 전역 호출 그래프(Global Call Graph)를 메모리에 생성하여, 사용되지 않는 전역 공통 함수(Unused Exported Functions)를 발견하고, 외부 사용자 입력이 `dbExecute()`나 `dpSet()`으로 전달되는 오염 경로(Taint Path)를 추적합니다.
* **기대 효과**: 심층적인 보안 취약점(SQL Injection) 및 멀티 모듈 아키텍처 결함을 근절합니다.

### 1.3 도메인 데이터 검증: PLC 및 SCADA 태그 데이터베이스 자동 대조
* **개선 배경**: 스크립트 내 `dpGet("Pump_01_Status")` 호출 시 실제 WinCC OA 프로젝트 DP(Data Point) 설정 데이터베이스에 해당 태그가 존재하는지 코드상으로 알 수 없습니다.
* **추가 기능**: WinCC OA DP 설정 XML 파일 또는 DB Export 정보를 로딩하여, 소스 코드 내 하드코딩된 태그명이 실제 존재하지 않는 무효 태그(Invalid Data Point)인 경우 정적 검사 단계에서 적발합니다.
* **기대 효과**: 현장 시운전 단계에서 발생하는 태그 이름 오탈자 런타임 오류를 100% 사전에 예방합니다.

### 1.4 개발자 경험(DX) 극대화: IDE 실시간 플러그인 (VS Code / WinCC OA Editor Extension)
* **개선 배경**: 코드 작성을 완료한 후 검사하는 방식에서 작성 직후 실시간 감지로의 전환이 요구됩니다.
* **추가 기능**: VS Code 및 WinCC OA 스크립트 에디터용 플러그인 형태로 개발하여, 개발자가 코드를 작성하는 순간 실시간 물결선 경고(In line Diagnostic) 및 즉시 자동 수정(Quick Fix) 조치를 제공합니다.
* **기대 효과**: 결함 발견과 수정 사이의 시간 간격을 0초로 단축합니다.

### 1.5 지능형 RAG 연동: 사내 표준 지식베이스 및 이력 기반 LLM 리뷰 (Enterprise Standard RAG)
* **개선 배경**: 정적 룰 외에 사내 특화 아키텍처 규칙이나 과거 숙련 엔지니어의 피드백 노하우 반영이 필요합니다.
* **추가 기능**: 사내 표준 가이드라인 PDF 및 기존 우수 리뷰 지식 베이스를 Vector DB(RAG)에 구축하여, AI 검증 시 명확한 사내 규정 근거와 권장 작성 가이드를 제시합니다.
* **기대 효과**: 단순 문법 지적을 넘어 아키텍처 수준의 고품질 페어 프로그래밍 조력자로 진화합니다.

## 2. 우선순위 및 타당성 평가 Matrix

* **1순위 (높은 효용, 보통 난이도)**: CI/CD MR 인라인 코멘트 봇
* **2순위 (높은 효용, 보통 난이도)**: SCADA 태그 데이터베이스 자동 대조 검증
* **3순위 (매우 높은 효용, 높은 난이도)**: 교차 파일 종속성 및 오염 추적 엔진
* **4순위 (높은 효용, 보통 난이도)**: IDE 실시간 플러그인 개발
* **5순위 (보통 효용, 높은 난이도)**: 사내 지식베이스 연동 LLM RAG
