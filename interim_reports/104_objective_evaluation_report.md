## 1. 평가 개요 및 과학적 방법론

본 평가에서는 WINCC OA 코드리뷰 자동화 프로그램의 품질, 정확도, 유지보수성, 신뢰성을 객관적인 실측 데이터에 기반하여 검증하였습니다.

### 평가 방법론 및 가증 절차
1. **단일 진실 출처(SSOT) 메트릭 검증**: `intermediate_results/single_source_metrics.json` 내 자동 수집 지표 활용
2. **자동화 테스트 및 커버리지 측정**: `pytest --cov=wincc_reviewer` 수행을 통한 코드 라인 커버리지 실측
3. **다단계 골든셋 벤치마크 평가**:
   * Real World Golden Set v2 (60개 웹 원본 표본)
   * Real World Golden Set v3 (34개 정제 원본 표본, 사전 봉인 무결성 적용)
   * Large Scale Synthetic Benchmark (210개 합성 테스트 표본)
4. **Anti Gaming 무결성 규칙 검증**: 지표 과장 차단 자동화 훅 및 골든셋 무결성 이상 탐지기 동작 확인

## 3. 방법 선택의 타당성 및 검증 근거

### 1) Tree sitter 기반 AST 분석과 정규식 체커의 하이브리드 구조
* **타당성**: CTRL(WinCC OA 스크립트 언어) 및 PNL(패널 XML) 구조는 단순 정규식만으로 스코프 및 변수 생명주기를 파악하기 어렵습니다. 따라서 Tree sitter AST 파서를 도입하여 제어 흐름 분석(CFA)을 수행하고, 정규식 기반 빠른 패턴 매칭을 보조적으로 배치하여 분석 정확도와 속도를 동시에 확보하였습니다.

### 2) Anti Gaming 7원칙 기반 무결성 보장 체계
* **타당성**: 자가 검증 보고 과정에서 발생할 수 있는 지표 부풀리기(Anti Gaming)를 방지하기 위해, 커밋 메시지의 주장이 SSOT 실측 데이터와 다를 경우 커밋을 자동으로 거부하는 검증 스크립트(`verify_commit_message_claims.py`)와 골든셋 무결성 이상탐지기(`validate_golden_set_integrity.py`)를 적용하여 측정의 객관성을 보존하였습니다.

## 4. 객관적 한계점 보고 (Limitations)

1. **합성 엣지케이스 데이터에서의 정밀도 하강**:
   * 합성 데이터 210개 분석 결과 Precision이 75.0%로 하강함. 이는 극단적 짝맞춤 오차나 의도적으로 중첩된 정규식 패턴에서 오탐(False Positive)이 발생하는 한계를 나타냄.

2. **AI 검증 모델의 비결정성 및 지연 시간**:
   * 로컬 AI Provider 연동 시 외부 LLM 응답 속도 및 프롬프트 결과의 미세한 비결정성으로 인해 100% 동기적 실시간 탐지에는 한계가 존재함.

3. **WinCC OA 전용 런타임 환경과의 결합도 한계**:
   * 정적 코드 분석 특성상 Dynamic Datapoints(dpGet, dpSet)의 실제 SCADA 런타임 갱신 주기나 데이터베이스 바인딩 상태까지 완전하게 추론하는 것은 불가능함.
