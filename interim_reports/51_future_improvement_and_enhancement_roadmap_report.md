# 51. 코드리뷰 자동화 시스템 부족점 분석 및 미래 고도화 개선 로드맵 보고서

## 1. 개요
본 보고서는 현재 완수된 WinCC OA 코드리뷰 자동화 시스템(`wincc_reviewer`)의 구현 현황을 객관적으로 진단하여, 향후 시스템의 완성도와 확장성을 한 단계 더 끌어올리기 위한 기술적 부족점과 이에 대한 세부 개선 방안을 정밀하게 제시한 문서입니다.

## 2. 현 시스템의 부족점 정밀 분석

### 2.1 체크리스트 자동화율의 상대적 한계
* **현상**: 현행 엑셀 체크리스트 기준 client 33.33%, server 30.0%의 룰만 정적 체커(AST/Regex/Builtin)로 자동 검사되며, 나머지 70%는 사람의 판단이 필요한 `MANUAL_REVIEW` 상태입니다.
* **원인**: CTL/PNL 스크립트 내 심층 제어 흐름(Control Flow) 및 변수 생명주기 추적 파서가 기본 정규식 및 내장 구문 분석 위주로 구성되어 있어, 복잡한 비즈니스 로직 룰을 정적으로 컴파일하는 데 기술적 한계가 존재합니다.

### 2.2 실검증 벤치마크 데이터셋의 다양성 부족
* **현상**: 테스트 픽스처 기반 정밀 평가 지표(Precision 100.0%, Recall 100.0%)는 확보되었으나, 다양한 고객사 현장의 구버전 WinCC OA(v3.15, v3.16 등) 대규모 프로젝트 소스에 대한 다양화된 벤치마크 데이터셋이 더 확충되어야 합니다.

### 2.3 실시간 IDE 에이전트 연동 부재
* **현상**: 현재는 커밋 후 CLI/GUI 검사 및 PR 인라인 주석 게시 중심의 배치형 워크플로우이며, 개발자가 소스를 작성하는 시점(Realtime)에 IDE에서 직접 결함을 피드백 받는 LSP(Language Server Protocol) 연동이 부재합니다.

### 2.4 자동 수정(Autofix) 패치 구문의 샌드박스 검증 절차
* **현상**: AI 및 룰 기반 자동 수정 제안 기능과 WinMerge Diff 비교는 구축되어 있으나, 제안된 수정 코드가 문법적으로 100% 결함이 없는지 구문 검증(Syntax Validation)을 수행하는 자동 샌드박스 루프가 추가 보완될 필요가 있습니다.

## 3. 영역별 디테일 개선 실행 방안 (Phase 5+)

### 3.1 영역 1: AST 정밀 파서 도입을 통한 자동화 커버리지 80% 이상 상향
* **실행 계획**:
  * `lark` 파서 라이브러리 기반 WinCC OA CTL 전용 정밀 AST 문법 파서 엔진 개발
  * DP(Data Point) 계층 변수 추적기(`DPVariableTracker`)를 구축하여 수동 검토 항목 중 12개 룰을 `builtin` 정적 체커로 전환
  * 수동 항목 70% 중 자동화 가능 범위를 80% 이상으로 획기적 상향

### 3.2 영역 2: 현장 데이터 소스 익명화 유틸리티 및 버짓 확장
* **실행 계획**:
  * 고객사 코드의 보안 민감 정보(IP, 계정, 서버명)를 자동 난독화하는 `scripts/04_anonymize_dataset.py` 스크립트 구현
  * WinCC OA 버전을 선택 반영할 수 있는 버전별 정적 체커 레지스트리 패키지 분리

### 3.3 영역 3: VS Code 전용 extension 및 LSP 연동 개발
* **실행 계획**:
  * VS Code 마켓플레이스 연동용 `wincc-reviewer-vscode` Extension 구축
  * 파일 저장 시(`onSave`) 배경 정적 파이프라인 기동 및 실시간 코드 밑줄(Diagnostics) 경고 시각화 연동

### 3.4 영역 4: 자동 수정 샌드박스 AST 구문 검증 루프 도입
* **실행 계획**:
  * `enable_autofix` 제안 패치 적용 시 `.autofix_temp.ctl` 임시 디렉토리에 샌드박스 저장 후 AST 파싱 테스트 시행
  * 문법 파손(PARSE_FAILED) 감지 시 자동 수정 패치를 롤백하고 안전성을 100% 보장하는 안전 가드 적용

### 3.5 영역 5: 장기 품질 트렌드 및 기술 부채 감축 대시보드 DB 연동
* **실행 계획**:
  * `intermediate_results/quality_trend_db.json` 영구 DB 구축
  * 프로젝트별, 월별 결함 감축률 및 핫스팟 제거 추이를 시각적 대시보드로 정기 레포팅하는 기능 확장

## 4. 결론 및 기대 효과
본 개선 계획을 수행할 경우, 자동화율이 현행 30% 수준에서 **80% 이상으로 대폭 향상**되며, 개발자 IDE 실시간 피드백부터 장기 기술 부채 감축 대시보드까지 완벽히 차별화된 최고 수준의 코드리뷰 자동화 에코시스템이 완성될 것입니다.
