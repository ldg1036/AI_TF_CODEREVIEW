## 2. 4대 차기 고도화 기능 세부 설계 및 의의

### 2.1 [심층 정적 분석] 교차 파일 종속성 및 오염 분석 (Inter-procedural Taint Analysis)
* **필요성 및 코드리뷰 의의**:
  * 현재 린터는 개별 `.ctl`, `.pnl` 파일 내부 스코프 검사에 탁월합니다. 하지만 실제 SCADA 프로젝트는 `#uses "ScopeLib"`를 통해 수십 개의 모듈이 연결되어 있습니다.
  * 복수 스크립트에 걸친 **"사용되지 않는 전역 공통 함수(Unused Exported Functions)"**와 **"사용자 화면 입력에서 유래된 문자열이 검증 없이 `dbExecute()` 쿼리로 전달되는 경로(SQL Injection Taint Path)"**를 추적해야 합니다.
* **구현 방안**:
  1. 전체 프로젝트의 `#uses` 선언을 구문 분석하여 프로젝트 전역 심볼 테이블(Global Symbol Graph)을 메모리에 구축합니다.
  2. 오염원(Source: UI 텍스트 필드 입력)부터 오염 지점(Sink: `dbExecute`, `system` 호출)까지 변수 흐름을 추적하는 데이터 흐름 도달성 체커(`ctl.ast.taint_analysis`)를 추가합니다.

### 2.2 [CI/CD 협업 파이프라인] Merge Request 인라인 코멘트 봇 (GitLab / GitHub CI 연동)
* **필요성 및 코드리뷰 의의**:
  * 개발자가 로컬이나 빌드 서버에서 생성된 HTML/PDF 리포트를 별도 여는 대신, 깃랩(GitLab)이나 깃허브(GitHub) 등 소스 형상관리 도구에서 **Merge Request / Pull Request를 생성할 때 해당 코드 라인에 자동 리뷰 봇이 댓글(Inline Comment)을 다는 워크플로**가 필요합니다.
* **구현 방안**:
  1. CLI 인자로 `--git-provider=gitlab --mr-id=102` 및 API 토큰을 입력받는 애드온 모듈을 구현합니다.
  2. Git Diff에서 변경된 파일과 라인을 추출한 후, 정적 분석 및 AI 검증에서 검출된 위반 사항을 Git Rest API를 통해 Merge Request 라인 주석으로 자동 등록합니다.
  3. 신뢰도 점수 0.80 이상 위반 존재 시 CI 빌드 파이프라인을 실패(Fail)시키거나 'Change Requested' 상태로 전환합니다.

### 2.3 [아키텍처 가시성] 기술 부채 핫스팟 히트맵 및 릴리스 품질 트렌드 대시보드
* **필요성 및 코드리뷰 의의**:
  * 아키텍트와 QA 리더는 특정 룰 위반뿐 아니라, **"우리 SCADA 프로젝트에서 결함이 가장 꼬여 있는 고위험 스크립트는 어디인가?"**를 직관적으로 조감하고 싶어 합니다.
  * 또한 릴리스(v1.0 -> v1.1 -> v1.2)를 거치며 품질이 개선되고 있는지, 아니면 신규 결함이 누적(Regression)되고 있는지 추이를 관제해야 합니다.
* **구현 방안**:
  1. HTML 리포트에 **'핫스팟 히트맵(Hotspot Heatmap)'** 탭을 추가하여 디렉터리 및 파일별 위반 빈도/심각도를 트리맵(Treemap) 그래픽으로 렌더링합니다.
  2. 이전 파이프라인 실행 기록(`run-xxx.json`) 이력을 데이터베이스나 캐시에서 불러와, "신규 결함(New)", "수정된 결함(Fixed)", "계속 존재하는 결함(Persistent)"을 꺾은선 차트로 보여주는 품질 대기열 대시보드를 구축합니다.

### 2.4 [룰 카탈로그 지능화] AI 오탐 피드백 기반 엑셀 룰 카탈로그 자율 최적화
* **필요성 및 코드리뷰 의의**:
  * 개발 팀이 리포트에서 특정 룰에 대해 반복적으로 "이 래퍼 함수는 프로젝트 공통이라 안전함(False Positive)"으로 표시할 경우, 룰 엔진이 이를 인지하여 엑셀 룰 자체를 정교화할 수 있어야 합니다.
* **구현 방안**:
  1. 사용자의 오탐 표시 이력을 JSON 로그로 누적합니다.
  2. 동일 패턴에서 3회 이상 오탐 처리된 경우, AI가 "룰 `CTL_PRF_001`의 검증 조건에 `safeDpSet` 제외 규칙을 추가할 것을 추천합니다"라는 제안 보고서를 생성합니다.
  3. 관리자 승인 시 엑셀 파일 서식의 B/C/D 열이나 YAML 설정을 자동으로 보정합니다.
