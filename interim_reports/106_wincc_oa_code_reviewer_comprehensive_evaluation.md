## 2. 방법 선택의 타당성 (Methodological Validity)

**도입 방법**: 다층 하이브리드 파이프라인 (Tree-sitter AST 파서 + 정규식 패턴 매칭 + AI LLM 심층 판정 및 RAG)

**선택 타당성**:
1. **SCADA 시스템의 비동기성**: WINCC OA의 이벤트 주도(Event-driven) 및 비동기 콜백 구조는 단순 정규식만으로 완벽한 문맥(Scope) 파악이 불가능합니다. 따라서 제어 흐름 분석(CFA)을 위해 Tree-sitter C++ 파서를 도입하여 노드 트리를 구축하는 것이 과학적으로 타당합니다.
2. **AI 환각 억제 (RAG)**: 범용 LLM은 존재하지 않는 함수를 임의로 생성할 위험이 있습니다. 공식 API 사서함을 Domain RAG 구조로 결합하고 Hard-Constraint 프롬프트를 주입하여 비결정적 출력을 통제하는 방식을 선택하였습니다.

## 4. 객관적 한계점 보고 (Limitations)

본 시스템은 높은 성능을 보이나 다음과 같은 객관적 한계가 존재함을 보고합니다.

1. **합성 엣지케이스에서의 탐지율 하강**
   * 의도적으로 복잡하게 꼬인 짝맞춤 오차나 과도하게 중첩된 구문을 포함한 210개 합성 벤치마크 데이터셋 분석 시, 정밀도가 75.0%로 하강하였습니다. 극단적 난독화 코드에 대한 방어 로직은 아직 불완전합니다.
2. **동적 런타임 제어 상태 파악 불가**
   * 프로그램이 정적 코드 분석에 기반하므로, SCADA 런타임 시점의 실제 데이터포인트 값 변동이나 외부 PLC 장비의 물리적 연결 상태 단절 위험까지 동적으로 검증할 수는 없습니다.
